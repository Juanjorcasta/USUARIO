# Juan.dev — Portfolio

Personal portfolio site for Juan José Castaño, software developer from Pereira, Colombia.

## Structure

```
Proyecto/
├── index.html        # Main HTML (all sections)
├── css/
│   └── styles.css    # All styles (dark/light theme, responsive)
├── js/
│   └── main.js       # Particles, typing effect, theme/language toggle, animations
└── README.md
```

## Features

- Dark/light theme toggle with `localStorage` persistence
- EN/ES language toggle (no external libraries)
- Canvas particle network animation
- Typewriter effect in the hero section
- Scroll-reveal animations (IntersectionObserver)
- Fully responsive layout
- `mailto:` contact form (no backend required)

## Fonts

Loaded from Google Fonts:
- **Space Grotesk** — headings/display
- **Inter** — body text
- **JetBrains Mono** — code labels and nav brand

## Deployment

Hosted on GitHub Pages. To deploy:

1. Push to the `main` branch of your GitHub repository
2. Go to **Settings → Pages** and set the source to `main` / `root`
3. Your site will be live at `https://<username>.github.io/<repo>/`
